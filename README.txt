ROYAL TASTE RESTAURANT WORDPRESS THEME
======================================

Installation:
1. WordPress Admin -> Appearance -> Themes.
2. Click Add New -> Upload Theme.
3. Select royal-taste-restaurant.zip.
4. Install and Activate.

Notes:
- This is a WordPress theme wrapper around the supplied React/Vite restaurant frontend.
- It uses React, ReactDOM, Tailwind Play CDN and Babel Standalone from public CDNs at runtime.
- The supplied restaurant images are included locally in assets/images.
- Restaurant menu, offers, reviews, reservation and ordering interactions are handled by the frontend.
